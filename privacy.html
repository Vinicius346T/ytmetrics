Política de Privacidade — YT Metrics

Última atualização: 21/10/2026

O YT Metrics é um programa pessoal para Windows que mostra métricas dos canais do YouTube do próprio usuário.

Dados acessados

Com a autorização do usuário (OAuth 2.0 do Google), o app lê, somente para leitura, dados do canal e dos vídeos pela YouTube Data API v3, YouTube Analytics API e YouTube Reporting API (escopos youtube.readonly e yt-analytics.readonly).

Armazenamento

Todos os dados ficam apenas no computador do usuário (banco SQLite local). O token de acesso fica no Gerenciador de Credenciais do Windows. Nenhum dado é enviado a servidores do desenvolvedor ou a terceiros; o app só se comunica com as APIs do Google.

Compartilhamento

Os dados não são vendidos, compartilhados nem usados para publicidade. O uso de dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Remoção

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Apagar a pasta %APPDATA%\YTMetrics remove todos os dados locais.

Também se aplicam os Termos de Serviço do YouTube e a Política de Privacidade do Google.
